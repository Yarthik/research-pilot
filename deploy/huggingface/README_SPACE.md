# ResearchPilot — live demo

An agentic research assistant over five well-known AI papers (Transformer, RAG, ReAct, LoRA,
Chain-of-Thought). Ask a question and watch the agent plan, retrieve, check its context and
answer with citations.

The demo's documents are fixed and the number of questions per session is limited, to keep it
free to run. Source code, architecture and evaluation results:
[github.com/Yarthik/research-pilot](https://github.com/Yarthik/research-pilot).
